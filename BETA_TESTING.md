# Beta Testing

Please test:

- one valuable unique dropping alone
- several tracked uniques dropping at once
- two copies of the same tracked unique
- unidentified to identified label changes
- picking up one item while other alerts remain
- different loot-filter font sizes
- connection arrows pointing to the correct item when several alerts are active
- different resolutions/aspect ratios
- poe.ninja threshold and refresh changes

## Reporting

1. Take a screenshot if the problem is visual.
2. Click **Create Support Bundle**.
3. Click **Open Support Issue**.
4. Describe what happened and what you expected.
5. Attach the generated ZIP if useful.
6. Review the issue before submitting.

Nothing is uploaded or submitted automatically.
