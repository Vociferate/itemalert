# Beta Testing

Please test the following before reporting a bug:

- one valuable unique dropping alone
- several tracked uniques dropping at once
- two copies of the same tracked unique
- unidentified to identified label changes
- picking up one item while other alerts remain
- connection arrows with multiple active alerts
- different loot-filter font sizes
- different resolutions and aspect ratios
- poe.ninja threshold changes
- poe.ninja league selector population
- switching between available poe.ninja economy leagues
- automatic repricing after changing league

## Reporting an Issue

1. Take a screenshot if the issue is visual.
2. Open ItemAlert settings.
3. Click **Create Support Bundle**.
4. Click **Open Support Issue**.
5. Describe what happened and what you expected.
6. Attach the generated support ZIP if useful.
7. Review the issue before submitting.

Nothing is uploaded or submitted automatically.

## Privacy

Support bundles may contain local installation paths. Review the ZIP before posting publicly if those paths contain information you do not want to share.
